# Luciola

![](brand/luciola.png)

Luciola is a decentralized social protocol. An **Identity** signs **Actions**; actions are stored on **Nodes** and flow between nodes along relationships.

- All nodes are equal: no central node, no global index, no shared blocklist.
- Identity belongs to the user, rooted in a master key the user holds.
- Content flows only along relationships, and every action is signed and verifiable on any node.
